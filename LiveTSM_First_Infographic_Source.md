# LiveTSM первая инфографика с выбором ОС

Редакция r10 · 13.10.2026.

## Первый PNG лист

Существующие шесть вопросов клиента и цена 12 000 ₽ сохраняются. Перед блоком демонстрации добавляется короткая седьмая карточка.

**Вопрос:** Нужно выбирать Linux или Windows?

**Ответ:** Linux или Windows — без перенастройки.

**Пояснение:** Администратор настраивает один раз. Пользователь выбирает разрешённую ОС через GRUB.

GRUB — GRand Unified Bootloader, загрузчик с меню выбора ОС. Подробности двух режимов, исключение shim и GRUB при прямом запуске Linux, штатная цепочка Windows и компромисс безопасности находятся в вопросах и ответах.

## Главная страница

Отдельная HTML-карточка над первой PNG-инфографикой удаляется. Короткий тезис находится внутри первой PNG-шпаргалки. Подпись под листом даёт ссылку на вопрос о выборе ОС. Развёрнутое сравнение остаётся внутри раскрываемого ответа.
