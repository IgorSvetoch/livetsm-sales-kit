## Штатный запуск без оператора

Для поддерживаемых NGFW, сетевых шлюзов и серверов администратор заранее настраивает автоматическую доверенную загрузку. LiveTSM проверяет заданные компоненты и запускает разрешённую ОС после успешных проверок. Штатный старт проходит без пароля пользователя и без подключённого личного токена; аппаратный модуль LiveTSM остаётся установленным. Настройки доступны аутентифицированному администратору.

Профиль ИТ.СДЗ.ПР4.ПЗ, который детализирует требования приказа ФСТЭК России № 119 для средств доверенной загрузки уровня платы расширения 4-го класса защиты, не требует идентифицировать и аутентифицировать пользователя при каждом штатном запуске. В перечень функциональных компонентов объекта оценки (таблица 5.1 профиля) не входят FIA_UID.2 и FIA_UAU.2, FIA_UAU.5, FIA_UAU.7.

Профиль ограничивает управление режимом функций безопасности уполномоченной ролью (FMT_MOF.1). В LiveTSM доступ к настройкам требует аутентификации администратора. Применимость режима проверяют по документации конкретного исполнения и требованиям системы заказчика.

[Профиль защиты ИТ.СДЗ.ПР4.ПЗ, раздел 5.1.1 и таблица 5.1](https://legalacts.ru/doc/itsdzpr4pz-metodicheskii-dokument-profil-zashchity-sredstva-doverennoi/). Ответы для продавца — в `LiveTSM_Sales_Cards.html#faq-headless`.

## Вопросы и ответы

### Можно ли выбирать Linux или Windows без вызова администратора

Да. Администратор один раз задаёт разрешённую конфигурацию: LiveTSM выполняет проверки и передаёт управление GRUB. Пользователь выбирает нужную ОС в меню. Для каждого переключения перенастройка LiveTSM не нужна; обновления и изменение разрешённой конфигурации обслуживаются по регламенту.

### Чем отличаются два режима загрузки

При прямой загрузке LiveTSM сам запускает ядро Linux, исключая shim и GRUB. В режиме совместимости LiveTSM запускает разрешённый GRUB, который позволяет выбрать ОС. Для Windows остаётся Windows Boot Manager. Полная сравнительная инфографика открывается внутри ответа; по умолчанию вопрос свёрнут.

### Какой режим выбрать администратору безопасности

Прямая загрузка Linux сокращает число доверенных компонентов. Режим совместимости даёт пользователю гибкость, но делает цепочку длиннее и расширяет поверхность атаки. Администратор осознанно принимает этот компромисс. Единственный разрешённый старт через LiveTSM должен сохраняться.

GRUB — GRand Unified Bootloader; EFI — Extensible Firmware Interface; shim — промежуточный EFI-загрузчик в некоторых схемах Linux; ОС — операционная система. Выбирается одна система при запуске, а не несколько одновременно.
