# LiveTSM sales kit r05

Публикационная версия комплекта. Главная страница — `index.html`.

## Что изменено

- лист `LiveTSM_Sales_03_Interfaces.png` заменён на трёхсценарную схему выбора подключения;
- добавлена инженерная карта `LiveTSM_Sales_06_M2_Connector_Map.png`;
- добавлена инструкция `LiveTSM_M2_OEM_Integration_Guide.docx` для производителей аппаратных платформ в корпоративном шаблоне;
- добавлен безопасный публичный архив `LiveTSM_Public_Sales_Kit_2026-09-21_r05.zip` для скачивания комплекта одним файлом;
- главная страница перестроена по маршруту «продукт → выбор интерфейса → проверка контактов → сценарии применения»;
- изображения подключаются отдельными файлами и не дублируются в HTML как Base64.

## Публикация

Содержимое папки можно разместить в корне статического сайта или GitHub Pages. Все ссылки относительные.

Публикационный архив не содержит внутренних справочников, ценовых материалов, служебных исследований и рабочих планов.
