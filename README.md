# LiveTSM — комплект продавца

Публичная HTML-версия комплекта материалов LiveTSM от 16.09.2026, редакция r04.

## Открыть

- `index.html` — главная страница сайта;
- `00_Start.html` — та же стартовая страница под исходным именем;
- `LiveTSM_Sales_Cards.html` — карточки продавца;
- `LiveTSM_Competitive_Analysis.html` — конкурентный обзор.

На главной странице используются пять полноразмерных PNG-листов. В репозитории также находятся два изображения изделий и два демонстрационных MP4-ролика без звука.

Внутренние рабочие документы, ценовые материалы, планы и технические записки в публичный репозиторий не включены.
