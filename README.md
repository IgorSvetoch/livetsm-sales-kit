# LiveTSM Sales Kit — r12

Редакция **r12 от 06.11.2026**. Откройте `index.html` или `00_Start.html`.

Сразу после первых двух инфографик на главной странице размещён третий визуальный лист **«Как выбрать исполнение LiveTSM»** с настоящими фотографиями JaCarta XL и M.2 из ТУ. На первом экране есть ссылка «Подобрать исполнение».

**Справочник продавца:** `LiveTSM_Sales_Cards.html#faq-models` — первый блок FAQ; содержит восьмистрочную таблицу из ТУ, аппаратные платформы, подключение, аутентификацию и советы по подбору.

**Источник:** `LiveTSM_Models_and_SKUs_Source.md`; графика — `LiveTSM_Sales_08_Models.svg`.

**Важно:** T110 и E110 доступны в конструктиве внутреннего USB XL или M.2 2230 A+E; C110 — внешний USB-A XL. Модуль M.2 использует **USB 2.0, не PCIe**. Совместимость конкретной платформы проверяется отдельно.

ТУ подтверждает состав восьми исполнений, но **не подтверждает** текущие продажи, складские остатки и комплектацию. Точные коммерческие SKU, наличие и сроки поставки нужно сверять с Salesforce.

РРЦ базового модуля **12 000 ₽**; остальные коммерческие условия — в КП. Документы DOCX и первые семь визуальных листов сохранены из r11 без изменений.
