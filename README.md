# LiveTSM — комплект продавца

Статический сайт, редакция r04. Главная страница — `index.html`.

Пять PNG-листов, карточки продавца, конкурентный разбор, Markdown-источники и два ролика без звука. Изображения изделий взяты из технических условий.

Планируемые функции обозначены отдельно от текущих. Материалы предназначены для подготовки коммерческого департамента.

Статус: загрузка материалов. Публикация сайта настраивается отдельно.
